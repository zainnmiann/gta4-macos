# Third-party files

This repo's [Releases](https://github.com/zainnmiann/gta4-macos/releases) page includes an **unmodified mirror** of the
Fusion Fix release I used. It's mirrored so this guide keeps working with the exact version that was tested.

| ↳ `dinput8.dll` (bundled in the zip) | Ultimate ASI Loader | ThirteenAG | MIT | <https://github.com/ThirteenAG/Ultimate-ASI-Loader> |

<https://github.com/ThirteenAG/GTAIV.EFLC.FusionFix/releases/download/v5.1.2/GTAIV.EFLC.FusionFix.zip>.
Its complete corresponding source code is at the GPL-3.0 source link above. All credit goes to the original authors.
